# План доработок Blossom Player

Делаем по одному пункту за раз, в этом порядке. Отмечаем `[x]` по завершении.
Каждый пункт — отдельный логический кусок, автосейв сам закоммитит и запушит
изменения после того, как правки устоятся.

## Фаза 1 — скачивание (использует уже имеющийся downloader-пайплайн)

- [x] 1. YouTube по ссылке → аудио: UI-поле "вставить ссылку на видео" → скачивание через `yt-dlp` → добавление в библиотеку. Протестировано end-to-end.
- [x] 2. Скачать всю дискографию артиста: ссылка на артиста в Spotify (через `spotapi`/веб-сессию) или канал/плейлист на YouTube (через `yt-dlp`) → массовая закачка в отдельный плейлист, с пропуском дублей. Протестировано (168 треков у реального артиста, список видео канала). Ограничение: берётся первая страница дискографии Spotify (обычно ~10 альбомов + ~10 синглов) и до 50 видео с YouTube-канала за раз.
- [x] 3. Инструментал: кнопка «Инстр.» у трека в библиотеке ищет "<артист> <название> instrumental" на YouTube и скачивает лучший результат как новый трек (<название> (Instrumental)). Протестировано end-to-end. По пути пришлось добавить обход антибот-блокировки YouTube (`player_client: android`) — без него yt-dlp стал получать "Sign in to confirm you're not a bot" на все запросы.

## Фаза 2 — качество библиотеки

- [x] 4. Аудио-отпечаток для поиска дублей: `fpcalc` (Chromaprint CLI, `tools/fpcalc/fpcalc.exe`, не в git) + своя Hamming-похожесть на части отпечатка (без внешних Python-биндингов — у pyacoustid конфликт имени пакета `chromaprint` с чужой либой на PyPI). Поле `fingerprint` в БД, кнопка «Дубли» в библиотеке запускает сканирование и показывает группы с удалением. Протестировано на реальной библиотеке: 20 групп дублей из 298 треков за ~18 сек, включая случаи с разными названиями (например, другая языковая версия).
- [x] 5. Обрезка начала/конца трека: кнопка «Обрез.» у трека — сколько секунд срезать с начала/конца. `ffmpeg -c copy` (без перекодирования) + принудительная перезапись ID3-тегов `mutagen` после обрезки. Протестировано: 150.675с → 135.672с (обрезали 5+10 сек), все теги (title/artist/album/date и др.) совпали побайтово до и после.

## Фаза 3 — распознавание (самые новые модули, зависят от Фазы 2)

- [ ] 6. OCR с картинки: распознать название/автора песни на фото или скриншоте (Tesseract OCR, офлайн, поддержка разных языков/алфавитов) → показать найденные варианты → по выбору отправить в закачку.
- [ ] 7. Shazam-модуль: распознавание трека по звуку (микрофон/аудио из видео) → определение названия и автора → проверка по отпечатку из п.4, не скачан ли уже → если нет, автоматически ставится в очередь закачки через существующий downloader.

## Примечания

- Ничего из этого не требует платных API — везде бесплатные открытые инструменты (`yt-dlp`, `spotdl`, `ffmpeg`, Tesseract, Chromaprint/AcoustID или `shazamio`).
- Для Shazam-распознавания используется `shazamio` (неофициальный клиент) — если он перестанет работать/будет заблокирован, резервный вариант — AcoustID (официальный, но хуже с зарубежными треками).
