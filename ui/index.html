Добавить из Spotify

Спотифай автоматически

Войди в свой аккаунт Spotify в открывшемся окне — все плейлисты и песни из них скачаются на устройство и в Google Drive. Дубликаты добавлены не будут.

Добавить с YouTube

Дискография артиста (Spotify)

Вставь ссылку на артиста Spotify или просто имя. Нужен вход в Spotify (через «Спотифай автоматически»). Все найденные треки скачаются и попадут в плейлист «Дискография: имя артиста». Дубликаты не скачиваются повторно.

Канал YouTube целиком

Вставь ссылку на канал (youtube.com/@имя) или плейлист. Скачается аудио из последних видео (максимум 50 за раз) в плейлист «YouTube: название».

Shazam: узнать трек по звуку

Поднеси устройство к источнику звука и нажми «Слушать» — или выбери готовый аудио/видео файл с записью песни. Если трека нет в библиотеке, он автоматически скачается с YouTube.

Распознать название с картинки

Подойдёт скриншот плейлиста, фото обложки с названием и т.п. Выбери язык текста на картинке для лучшего распознавания.

Обрезать начало/конец

Без потери тегов (название/автор сохранятся). Действие необратимо для самого файла — обрезанный кусок не восстановить.

Нашла инструментал

Можно сначала прослушать на YouTube, прежде чем скачивать.

Дубли по звуку

Сравнение идёт по звучанию файла, а не по названию/автору — найдёт дубли, даже если один скачан с Spotify, а другой с YouTube под другим именем. Первый прогон может занять время — нужно построить отпечаток для каждого трека.

Локальный трек

Если в имени файла есть тире — часть до него возьмём как исполнителя, после — как название
